# 验证流程 VALIDATION.md

本文档提供从初始空数据到完整功能验证的复现步骤。所有操作均使用合成演示数据。

## 前置条件

- PowerContext Server 已启动并监听 `http://127.0.0.1:18000`
- StudyRelay 应用已启动并监听 `http://127.0.0.1:18080`
- 浏览器可访问 `http://127.0.0.1:18080`

## 验证 1：初始空数据 → 偏好写入

### 步骤

1. 打开 http://127.0.0.1:18080
2. 确认健康徽章显示"PowerContext 已连接"（绿色）
3. 选择"小明（合成演示）"空间
4. 在学习设置中：
   - 每日复习分钟数：输入 `30`
   - 学习目标：输入 `掌握数据库索引原理`
5. 点击"保存设置"

### 预期结果

- 状态行显示：`已保存到 PowerContext（XXms, artifact: xxx...）`
- 设置表单隐藏，显示当前偏好：`30 分钟/天 · 掌握数据库索引原理`
- 修改设置按钮出现

### 验证 PowerContext 数据

```bash
# 列出 Scope 中的 study-preferences 记忆
curl -X POST http://127.0.0.1:18000/v1/atomic-memory/list \
  -H "Content-Type: application/json" \
  -d '{"scope_id": "<实际scope_id>", "kind": "study-preferences", "states": ["active"], "limit": 10}'
```

应返回至少 1 条记录，text 字段包含 JSON 格式的偏好数据。

## 验证 2：复习计划生成

### 步骤

1. 保存偏好后，页面自动加载"今日复习计划"
2. 查看计划摘要

### 预期结果

- 计划显示：`10 张卡片，预计 XX 分钟`（初始空数据，所有卡片为新卡片）
- 接续理由：`尚无学习记录，从全新卡片开始，优先安排高难度内容。`
- 卡片按难度从高到低排序：CAP 定理(5) → WAL 机制(4) → 实验偏差(4) → ...
- 每张卡片标记为"新卡片"（蓝色标签）

## 验证 3：复习卡片 → 自评 → 保存学习记录

### 步骤

1. 点击第一张卡片（难度最高的新卡片）
2. 阅读题干，点击"显示答案"
3. 选择"需加强"
4. 可选：输入笔记
5. 点击"保存本次学习"

### 预期结果

- 状态行显示：`已保存（XXms） artifact: xxx... rev:1 scope: xxx...`
- "下一张卡片"按钮出现
- 记忆面板中新增一条记录

### 验证 PowerContext 数据

```bash
curl -X POST http://127.0.0.1:18000/v1/atomic-memory/list \
  -H "Content-Type: application/json" \
  -d '{"scope_id": "<实际scope_id>", "kind": "study-record", "states": ["active"], "limit": 10}'
```

应返回至少 1 条记录，text 字段包含 JSON 格式的学习记录（card_id、assessment、date 等）。

## 验证 4：薄弱点优先排程

### 步骤

1. 复习 3 张不同卡片：
   - 卡片 A：自评"需加强"
   - 卡片 B：自评"已掌握"
   - 卡片 C：自评"需加强"
2. 刷新页面或重新进入计划

### 预期结果

- 卡片 A 和 C 在下次计划中优先出现（标记为"需加强"红色标签）
- 卡片 B 不在当天计划中（已掌握，延后 3 天）
- 接续理由说明：`共 3 条学习记录，覆盖 3 张卡片；其中 2 次「需加强」；1 次「已掌握」...`

## 验证 5：持久化恢复（重启验证）

### 步骤

1. 完成验证 1-4 后，关闭应用（Ctrl+C）
2. 重新启动应用：`.\start.ps1` 或 `./start.sh`
3. 打开浏览器，选择同一空间

### 预期结果

- 偏好设置从 PowerContext 恢复（不需要重新输入）
- 学习记录从 PowerContext 恢复
- 复习计划基于历史记录正确生成
- 记忆面板显示之前的所有记录

## 验证 6：空间隔离

### 步骤

1. 在"小明"空间完成若干复习
2. 切换到"小红"空间
3. 查看小红的偏好和记录

### 预期结果

- 小红的空间没有小明的偏好数据（需要重新设置）
- 小红的空间没有小明的学习记录
- 计划显示所有卡片为"新卡片"
- 两个空间的 Scope ID 不同

## 验证 7：数据导出

### 步骤

1. 在记忆面板中点击"导出 JSON"
2. 再次点击"导出 Markdown"

### 预期结果

- JSON 文件下载，包含 space_id、scope_id、preferences、records
- Markdown 文件下载，包含格式化的学习记录
- 导出内容中不包含 token 或敏感信息
- 每条记录包含 artifact_id、revision 等真实记忆引用

## 验证 8：PowerContext 不可用降级

### 步骤

1. 停止 PowerContext Server
2. 刷新应用页面

### 预期结果

- 健康徽章显示"PowerContext 不可用"（红色）
- 出现错误提示弹窗
- 依赖记忆的操作（保存偏好、保存学习记录、加载计划）显示错误
- 不显示虚假的 localStorage 数据

## 验证 9：自定义空间

### 步骤

1. 在"添加新学习空间名称"输入框输入 `我的学习空间`
2. 点击"添加"

### 预期结果

- 新空间出现在空间列表中
- 标记为自定义空间（无"合成演示"标签）
- 拥有独立的 Scope ID
- 可以设置偏好和进行复习

## 验证 10：排程逻辑确定性

### 步骤

1. 在相同数据状态下，多次刷新计划页面
2. 对比每次的卡片顺序

### 预期结果

- 卡片顺序完全一致
- 优先级标签一致
- 接续理由文本一致
- 排程结果可解释，无随机因素
