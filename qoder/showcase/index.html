续学 StudyRelay

会记住进度的复习助手

基于 PowerContext 本地记忆服务，为学习与科研场景提供持久化复习进度、薄弱点优先排程、可解释学习规划。

合成演示数据 本地运行 无云端推理 PowerContext 1.5.0

项目简介

续学 StudyRelay 解决学习和科研中"每次重新说明薄弱点、复习进度散落"的痛点。它将学习偏好和复习记录持久化到 PowerContext 本地服务，每次打开应用时自动从记忆系统恢复进度，生成"上次学到哪里""薄弱点优先"的复习计划。

持久化记忆

学习偏好和复习记录写入 PowerContext Atomic Memory，重启后完整恢复。

薄弱点优先

确定性的排程逻辑：需加强卡片优先，已掌握卡片延后 3 天，不伪称智能推荐。

真实引用

展示每次记忆写入/召回的 artifact_id、revision、scope 和请求耗时。

空间隔离

不同学习空间使用独立 PowerContext Scope，数据完全分区。

痛点分析

进度散落

复习记录分散在不同笔记、App 中，无法统一查看哪些已掌握、哪些需加强。

重复说明

每次打开新工具都要重新输入学习目标和薄弱环节，没有持久记忆。

黑箱推荐

很多学习 App 声称"智能推荐"，但排程逻辑不透明，用户无法理解和信任。

核心流程

1

选择空间

选择合成演示用户或创建新学习空间，每个空间对应独立 PowerContext Scope。

2

设置偏好

设定每日复习分钟数和学习目标，显式保存后写入 PowerContext Atomic Memory。

3

查看计划

系统从 PowerContext 读取历史记录，生成薄弱点优先的复习计划。

4

复习与自评

逐张复习卡片，自评"需加强"或"已掌握"，保存后写入新的学习记录。

5

导出记录

支持导出 JSON 或 Markdown 格式，包含真实记忆引用，不含 token。

本地运行

环境要求

  • Python 3.12+
  • PowerContext Server 1.5.0（powercontext[cli,server]==1.5.0）
  • Windows 10/11（已验证）或 POSIX 系统

快速启动

# Windows PowerShell
.\start.ps1

# POSIX (bash/zsh)
chmod +x start.sh
./start.sh

手动启动

# 1. 设置环境变量
$env:POWERCONTEXT_HOME = Join-Path (Get-Location) '.data/powercontext'

# 2. 启动 PowerContext Server（独立终端）
powercontext server run --host 127.0.0.1 --port 18000 --no-env-file

# 3. 启动应用
uvicorn app.main:app --host 127.0.0.1 --port 18080

# 4. 打开浏览器访问
# http://127.0.0.1:18080

排程逻辑验证样例

场景：初始空数据

  1. 选择"小明（合成演示）"空间
  2. 设置每日 30 分钟，目标"掌握数据库索引"
  3. 查看计划：应显示高难度卡片优先（B+树、CAP定理等）
  4. 复习第一张卡片，自评"需加强"
  5. 保存后刷新：该卡片应在下次计划中继续优先出现

场景：已掌握卡片延后

  1. 复习一张卡片，自评"已掌握"
  2. 当天再次查看计划：该卡片不应出现
  3. 3 天后查看计划：该卡片应重新出现（标记为"到期复习"）
