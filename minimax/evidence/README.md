# 原始验证记录索引

| 记录 | 内容 |
|---|---|
| `minimax-development.json` | 真实 MiniMax 请求、完整提供上下文、最终代码、响应 ID、时间与用量；只选择最终回答，未保存私有推理或认证信息 |
| `model-input/` | 实际交给 MiniMax 的 seekdb 查询上下文及对应原始 SQL / PowerContext 记录；由准备运行 42381953457 产生，工程文件版本与本次开发输入一致 |
| `development/` | 真实输出对应的修改前后源文件、统一 diff 和哈希清单 |
| `local-reports/` | 本机同组测试的修改前后结果，目标退出码 1 → 0，回归 0 → 0 |
| `verification/` | Linux 干净环境完整验收 42428924105 的原始产物：12 项测试、业务测试、数据库查询、状态恢复、新规格上下文及命令/代码版本 |
| `minimax-attempt.json` | 早期按量 Key 余额不足的失败历史；已标记解决。该记录不被算作成功的 MiniMax 参与 |

`model-input/context.json` 是真实模型调用所用的输入；`verification/context.json` 是干净环境重放时重新从真实数据库生成的输入。它们的工程文件与任务哈希一致，但独立运行的记忆引用与时间不同。真实调用与重放的来源版本、输出代码和不变测试哈希可逐项核对。

所有文件均为记录或演示工程资料，不需要交付大型 seekdb 数据目录。验收会从空目录重新建立数据库并执行查询，而不是依赖预置数据库文件。
